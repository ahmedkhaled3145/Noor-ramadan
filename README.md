 # 🌙 Noor Ramadan System

Noor Ramadan System is a console-based C++ application designed to help Muslims stay consistent and motivated during the holy month of Ramadan. The system combines spiritual tracking, daily organization, and Islamic content into one interactive platform.

---

## ✨ Features

### 🔐 User Authentication System
- Sign up and login with password and recovery hint  
- Admin role with special permissions  

### 📊 Daily Progress Tracking
- Track the 5 daily prayers  
- Record Qur’an reading (pages)  
- Monitor daily tasbeeh (ذكر) count  
- Generate a detailed daily report with feedback  

### 🎯 Goal Management
- Set personal daily goals for Qur’an and tasbeeh  
- Evaluate performance against goals  

### 📿 Digital Rosary (Tasbeeh Counter)
- Interactive counter with increment, reset, and save functionality  
- Automatically updates daily progress and points  

### 🕌 Athkar & Doaa Library
- Browse categorized athkar (morning, evening, after الصلاة, etc.)  
- Browse various doaa categories (repentance, healing, Laylat Al-Qadr, etc.)  
- Admin can add new athkar and doaa  

### 📅 Ramadan Calendar
- View full Ramadan calendar or specific days  
- Store prayer times, daily events, and notes  
- Admin can update prayer times and events  

### 🏆 Gamification System
- Earn points based on activity (prayer, Qur’an, tasbeeh)  
- User ranking system:  
  - مبتدئ (Beginner)  
  - مثابر (Persistent)  
  - متدين (Devout)  

### 💾 Data Persistence
- Saves and loads users, progress, athkar, doaa, and calendar data using files  

### 📖 Daily Hadith
- Displays a random hadith each time the program starts  

---

## 🛠️ Technologies Used
- C++  
- File Handling (fstream)  
- Console UI  
- Windows-specific encoding support for Arabic text  

---

## 🎯 Purpose

This project aims to encourage consistency in worship during Ramadan by combining spirituality with simple tracking and motivational feedback, all within a lightweight console application.
